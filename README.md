# سیم‌بان (Simban) 🔌

> **سیم‌بان** ماژول اختصاصی **پایش سلامت، متادیتای پورت‌ها/مک‌ها و وب‌ترمینال سوییچ‌های سیسکو** در بستر اکوسیستم **بوم‌بان (Boomban Suite)** است.
> 
> *توجه:* تمامی تحلیل‌های کلان توپولوژی شبکه، ممیزی کابل‌ها، گزارش‌های عیب‌یابی و گراف ارتباطات در سامانه مرکزی **بوم‌بان** مدیریت می‌شوند. سیم‌بان صرفاً بر پایش وضعیت سوییچ‌ها، استخراج اطلاعات پورت‌ها و ارائه وب‌ترمینال سبک متمرکز است.

---

## 🎯 ۱. قابلیت‌ها و وظایف اصلی

- **پایش پیوسته وضعیت و تأخیر (Health Probe & Latency):** بررسی مداوم آنلاین/آفلاین بودن سوییچ‌ها با پینگ، اندازه‌گیری تأخیر پاسخ‌دهی (Latency بر حسب میلی‌ثانیه) و ثبت زمان آخرین پاسخ (`last_seen`).
- **وب‌ترمینال بلادرنگ (Web Terminal):** دسترسی مستقیم به محیط متنی و خط فرمان (CLI) سوییچ با WebSocket و قطع خودکار سشن‌های غیرفعال (Idle Timeout).
- **استخراج وضعیت پورت‌ها و مک‌ها (Port & MAC Inventory):** استخراج مدل، نسخه IOS، پورت‌های فعال/Up و مک‌آدرس‌های متصل به پورت‌ها جهت همبستگی با دوربین‌های مداربسته و رادیوها در بوم‌بان.
- **کشف ساب‌نت (Subnet Discovery):** اسکن پورت‌های Telnet/SSH جهت شناسایی سوییچ‌های جدید سیسکو در شبکه.
- **ارائه REST API ماشین‌خوان برای بوم‌بان:** ارائه اطلاعات لحظه‌ای سوییچ‌ها و وضعیت پورت‌ها روی پورت استاندارد **`23458`**.

---

## 🚀 ۲. راه‌اندازی و اجرا

داشبورد وب و وب‌ترمینال سیم‌بان به صورت پیش‌فرض روی پورت **`23458`** اجرا می‌شود:

### ویندوز (PowerShell):
```powershell
# اجرای منوی تعاملی و مدیریت کامل
.\start.ps1

# یا اجرای مستقیم در پس‌زمینه روی پورت استاندارد
.\start.ps1 -Action start-bg -Port 23458
```

### اجرای مستقیم با پایتون:
```bash
# اجرای وب‌سرور و زمان‌بندی کارهای پس‌زمینه
uvicorn app.main:app --host 0.0.0.0 --port 23458
```

داشبورد روی آدرس زیر در دسترس خواهد بود:  
`http://localhost:23458`

## 🌐 ۳. اندپوینت‌های وب‌سرویس و REST API (پورت ۲۳۴۵۸)

| اندپوینت | متد | شرح کاربرد |
| :--- | :---: | :--- |
| `/` | `GET` | داشبورد وب پایش سلامت، لیست سوییچ‌ها و لانچر وب‌ترمینال |
| `/terminal/{switch_ip}` | `GET` | صفحه اختصاصی وب‌ترمینال سوییچ |
| `/ws/terminal/{switch_ip}` | `WebSocket` | پل ارتباطی سوکت دوطرفه با ترمینال CLI سوییچ |
| `/api/switches` | `GET` | فهرست ماشین‌خوان سوییچ‌ها (IP، مدل، لتنسی، وضعیت، پورت‌های Up) |
| `/api/switches/{ip}/ports` | `GET` | جزئیات تک‌تک پورت‌ها، وضعیت و مک‌آدرس‌های متصل به هر پورت |
| `/api/config` | `GET/POST` | تنظیمات ساب‌نت، اعتبارنامه‌ها و زمان‌بندی |
| `/api/tasks` | `GET` | وضعیت جاب‌های زمان‌بندی‌شده پس‌زمینه |
| `/api/stream-log/{action}` | `GET (SSE)` | استریم لاگ اجرای تسک‌های اسکن، پایش پینگ و جمع‌آوری پورت‌ها |

## 🗄️ ۴. منبع داده‌های محلی

- **مسیر دیتابیس:** `data/network.db` (SQLite)
- **جداول اصلی:**
  - `switches`: مشخصات، لتنسی، زمان پاسخ و وضعیت آنلاین سوییچ‌ها
  - `switch_ports`: وضعیت پورت‌ها، شماره پورت، وضعیت Up/Down، سرعت و مک‌های شناسایی‌شده
  - `links`: لینک‌های متقابل سوییچ‌ها و اطلاعات CDP
  - `tasks`: زمان‌بندی کارهای خودکار در پس‌زمینه
