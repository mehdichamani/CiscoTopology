# راهنمای اسکریپت ارتقای اتصال سوئیچ به SSH (`upgrade2sshwithenv.py`) 🔐

اسکریپت `upgrade2sshwithenv.py` یک ابزار خودکار برای مهاجرت امن سوئیچ‌های سیسکو از پروتکل ناامن Telnet به SSHv2 همراه با امکان احراز هویت کلید عمومی (Public Key Authentication) بدون ایجاد وقفه یا قطع دسترسی ادمین است.

---

## 🎯 اهداف و منطق کارکرد

1. **حفظ ارتباط اولیه:** اتصال ابتدا با متد قدیمی Telnet برقرار می‌شود.
2. **پیکربندی هویت:** تنظیم Domain Name و Hostname در صورتی که روی سوئیچ ست نشده باشد.
3. **ساخت کاربر ادمین:** ایجاد کاربر با بالاترین سطح دسترسی (`privilege 15`) و رمزنگاری `secret`.
4. **تولید کلید RSA:** ایجاد Host Key روی سوئیچ جهت فعال‌سازی پردازش‌های SSHv2.
5. **تفکیک احراز هویت AAA (گام ۴.۵ امنیتی):**
   - احراز هویت دیتابیس محلی برای کاربران SSH.
   - ورود مستقیم خطی برای نشست‌های Telnet بدون نام کاربری جهت جلوگیری از قفل شدن دسترسی.
   - فعال‌سازی هم‌زمان `transport input telnet ssh` روی خطوط VTY.
6. **تزریق کلید عمومی SSH:** تبدیل کلید عمومی سیستم محلی کلاینت (`.pub`) به هش MD5 و تزریق آن به سوئیچ با دستور `ip ssh pubkey-chain`.
7. **ذخیره‌سازی و ارزیابی نهایی:** ذخیره کانفیگ در NVRAM (`write memory`) و اجرای تست اتصال SSH بدون نیاز به وارد کردن کلمه عبور (Passwordless Verification).

## 💻 نحوه استفاده

### ۱. اجرای پیش‌فرض:
اسکریپت به صورت خودکار فایل `upgrade2ssh.env` موجود در همان مسیر را می‌خواند:
```powershell
python scripts/upgrade2sshwithenv.py
```

### ۲. اجرا با فایل کانفیگ سفارشی:
می‌توانید مسیر یک فایل env دیگر را به عنوان آرگومان به آن بدهید:
```powershell
python scripts/upgrade2sshwithenv.py path/to/switch_specific.env
```

## 🔍 عیب‌یابی و خطاهای رایج

* **خطای `Authentication failed` در اتصال تلنت:**
  بررسی کنید که آیا سوئیچ برای ورود نیاز به نام‌کاربری دارد یا فقط پسورد لاین تنظیم شده است (`TELNET_USERNAME`). همچنین تطابق `TELNET_ENABLE_PASSWORD` را چک کنید.
* **عدم تولید کلید RSA:**
  تولید کلید RSA نیازمند ست بودن دامنه (`SWITCH_DOMAIN`) است. مطمئن شوید این فیلد در env مقدار دارد.
* **خطای `Incomplete command` در بخش pubkey-chain:**
  برخی نسخه‌های قدیمی Cisco IOS از ساختار `ip ssh pubkey-chain` پشتیبانی نمی‌کنند؛ در این شرایط اسکریپت با رمز عبور عادی SSH کار خواهد کرد.
