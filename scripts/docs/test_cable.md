# راهنمای ابزار تست سخت‌افزاری کابل شبکه (`test_cable.py`) 🔌

اسکریپت `test_cable.py` ابزاری تعاملی و مبتنی بر خط فرمان جهت ارزیابی سلامت فیزیکی کابل‌های شبکه متصل به سوئیچ‌های سیسکو با بهره‌گیری از فناوری بازتاب‌سنجی دامنه زمانی (**Time-Domain Reflectometry - TDR**) است.

---

## 🎯 قابلیت‌های کلیدی

1. **یکپارچگی با دیتابیس سیم‌بان:** خواندن خودکار اسامی، IP و مدل سوئیچ‌ها از دیتابیس `simban/data/network.db`.
2. **منوی تعاملی انتخاب سوئیچ و پورت:** امکان انتخاب آسان سوئیچ و سپس مشاهده لیست پورت‌های فیزیکی همراه با وضعیت جاری (`connected`، `notconnect` یا `err-disabled`).
3. **پشتیبانی از اجرای مستقیم خط فرمان:** ارسال مستقیم IP و نام اینترفیس بدون نیاز به ورود به منوی تعاملی.
4. **تست دقیق سخت‌افزاری (Cisco TDR):** اجرای فرمان `test cable-diagnostics tdr interface <port>` و انتظار هوشمندانه برای تکمیل سیگنال‌دهی پالس الکتریکی.
5. **پارس و تحلیل ۴ زوج‌سیم (Pair A, B, C, D):** تشخیص نوع قطعی یا سلامت برای هر زوج به همراه متراژ دقیق کابل و محل خرابی.

---

## 💻 نحوه استفاده

### ۱. حالت تعاملی (Interactive Mode)
در این حالت لیست سوئیچ‌ها از دیتابیس خوانده شده و شماره‌گذاری می‌شود:
```powershell
python scripts/test_cable.py
```
* سوئیچ مورد نظر را با شماره انتخاب کنید.
* اسکریپت پورت‌های فیزیکی را استخراج کرده و نمایش می‌دهد.
* شماره پورت مورد نظر را برای اجرای تست پالس TDR انتخاب کنید.

### ۲. حالت مستقیم (Direct CLI Execution)
در صورت تمایل به تست سریع یا اسکریپت‌نویسی خودکار:
```powershell
python scripts/test_cable.py 192.168.30.13 GigabitEthernet1/0/5
```

## 📊 راهنمای تفسیر نتایج TDR

خروجی تست کابل وضعیت هر جفت سیم را در ستون‌های زیر گزارش می‌کند:

| وضعیت (Status) | مفهوم فنی | اقدام پیشنهادی |
| :--- | :--- | :--- |
| **Normal** | زوج‌سیم کاملاً سالم بوده و دارای خاتمه صحیح (Terminated) است. | کابل سالم است و مشکلی ندارد. |
| **Open** | مدار باز (قطع بودن سیم) در متراژ اعلام‌شده. اگر کابل به دستگاهی وصل نباشد، در انتهای کابل این وضعیت طبیعی است. | در صورت اتصال کابل به کلاینت، کانکتور یا کیستون را بررسی کنید. |
| **Short** | اتصال کوتاه فیزیکی بین دو رشته سیم در زوج مورد نظر. | سوکت یا کابل آسیب دیده و باید تعویض شود. |
| **Impedance Mismatch** | عدم تطابق امپدانس (ناشی از خمش شدید، کشیدگی، نویز القایی یا کیفیت پایین کابل). | بررسی مسیر کابل و کیفیت پچ‌کورد. |

*نکته درباره متراژ:* متراژ اعلام‌شده با دقت حدود $\pm 1$ متر تا محل اتصال یا قطعی محاسبه می‌شود.

## ⚠️ نیازمندی‌ها و محدودیت‌ها

- سوئیچ و ماژول فیزیکی باید از فرامین سری Cisco TDR پشتیبانی کنند (در مدل‌های لایه ۲ قدیمی مانند برخی سری‌های غیراستاندارد 2950 ممکن است در دسترس نباشد).
- برای اجرای بدون مشکل، متغیرهای اتصال (`SWITCH_USERNAME`، `SWITCH_PASSWORD`، `SWITCH_SECRET` و غیره) باید در فایل `.env` پروژه تعریف شده باشند.
