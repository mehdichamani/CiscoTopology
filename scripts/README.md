# مستندات اسکریپت‌های کاربردی و نگهداری سیم‌بان 🛠️

این بخش شامل ابزارها و اسکریپت‌های تخصصی جهت ارتقای امنیتی، نگهداری، خطایابی سخت‌افزاری و تست کابل‌های متصل به سوئیچ‌های سیسکو در اکوسیستم **سیم‌بان / بوم‌بان** است.

---

## 📋 فهرست اسکریپت‌ها و ابزارها

| نام اسکریپت | هدف و کاربرد | پیش‌نیازها | سند اختصاصی |
| :--- | :--- | :--- | :---: |
| **`upgrade2sshwithenv.py`** | ارتقای خودکار اتصال سوئیچ از Telnet به SSH با تنظیمات کامل AAA و کلید RSA بدون قطعی ارتباط | `netmiko`, `upgrade2ssh.env` | [مشاهده سند اختصاصی](./docs/upgrade2ssh.md) |
| **`test_cable.py`** | اجرای تست سخت‌افزاری TDR بر روی پورت‌های سوئیچ جهت تشخیص قطعی، اتصال کوتاه و تخمین متراژ کابل | `netmiko`, `data/network.db` | [مشاهده سند اختصاصی](./docs/test_cable.md) |
| **`bench_test_cable.py`** | تست سریع پچ‌کوردها و کابل‌های جدید روی میز تست واحد IT (VLAN 998 ایزوله) بدون نیاز به تنظیمات دستی | `netmiko`, اتصال به سوئیچ تست | [مشاهده سند اختصاصی](./docs/bench_test.md) |

---

## 🚀 پیش‌نیازها و راه‌اندازی عمومی

کلیه اسکریپت‌ها با پایتون ۳ نوشته شده‌اند و به پکیج‌های ارتباطی سیسکو نیازمند هستند:

```powershell
# نصب وابستگی‌های مورد نیاز در صورت عدم وجود
pip install netmiko python-dotenv
```

برای آگاهی از نحوه استفاده، پارامترهای هر ابزار و خطایابی، به سند اختصاصی مربوط به همان اسکریپت در پوشه [docs/](./docs/) مراجعه نمایید.
